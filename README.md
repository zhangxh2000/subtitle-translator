# 字幕拾词 (SubPick)

一个 Android 悬浮窗应用，看视频时翻译屏幕上的字幕，并把遇到的生词收藏起来复习。

## 功能特性

- 🎯 **一键翻译**：悬浮按钮，点击即可翻译当前字幕
- 📝 **完整翻译**：显示原文和中文译文
- 📚 **重点词汇**：自动提取难词并显示词典释义
- 🔒 **离线翻译**：基于 ML Kit，无需联网即可翻译（首次需下载语言包）
- ☁️ **云端翻译**：登录后自动使用云端翻译（免费账号每日 10 次，会员不限）；游客只用本机 ML Kit，云端失败自动回退离线
- ✨ **AI 翻译纠错（会员）**：译文区的 AI 图标上传字幕截图，重新识别并精译当前句；
  成功时原文、译文与生词同步更新，请求中图标旋转，失败保留基础译文
- 🎬 **视频兼容**：支持 YouTube、Netflix、B站等任何视频应用
- ⏯️ **智能控制**：自动暂停/恢复视频播放
- ⏮️ **字幕导航**：翻译面板里可跳上一句/下一句；通过 MediaSession 精确 seek，自动识别字幕边界（需通知使用权）
- 📋 **一键复制**：长按原文/译文/单词即可复制到剪贴板
- 🏠 **首页总览**：悬浮翻译开关、当前语言、通知/无障碍权限状态、今日翻译数、单词复习进度，
  以及近三天翻译记录；记录可在当天内前后切换，已收藏单词在句中高亮
- 📜 **最近翻译**：按天汇总成功翻译的字幕；点某一天查看当天全部记录，
  「查看全部」按时间倒序查看所有记录；句子被收藏过时书签点亮
- 📚 **词汇本**：收藏时保留字幕上下文，支持搜索、单词/短语筛选和排序
- 🎓 **学习中心**：本地单词卡片复习，认识累计 3 次自动标记为已掌握；每日复习目标与进度
- ⚙️ **语言设置**：支持多语言对切换（英/日/韩/法/德/西等）
- 👤 **账号体系**：邮箱注册/登录、Token 自动刷新、启动恢复登录态；游客可正常翻译并在额度内本地收藏
- 🧭 **Material 3 导航**：首页 / 词汇 / 学习 / 我的四个底部入口；设置与关于在“我的”页
- ☁️ **云端同步**：登录后生词与句子收藏自动增量同步；离线先写本地、联网自动补发，多设备自动合并

### 分层与 MVVM 约束

- `ui/`：Activity 只负责渲染和系统交互；每个页面配套 `XxxViewModel`，用 `by viewModels()` 获取。
- ViewModel 负责业务状态与数据编排：用 `viewModelScope` 执行异步任务，通过 `LiveData` 暴露状态、`Event` 暴露一次性事件。
- `data/`：可写数据库（生词库与学习状态）、文件（调试截图）、SharedPreferences（`SettingsStore`）、鉴权会话等数据源。
- `domain/`：与 Android 无关的接口和模型。

强制规则见 [`CLAUDE.md`](CLAUDE.md)。

## 核心模块

### 1. 翻译通道 (`domain/translator/`、`data/translator/`)
- `ITranslator`：翻译接口，支持多种实现
- `MLKitTranslator`：ML Kit 离线翻译，支持自动重试下载语言包
- `BackendTranslator`：调用应用后端的 `POST /api/v1/translations/text`，第三方凭据只在服务端
- `AccountAwareTranslator`：按登录态选择通道；游客只走本地，登录用户优先云端，失败或额度用尽回退本地
- `CloudQuotaGuard` / `CloudQuotaCache`：缓存服务端下发的当日额度，额度为 0 时跳过云端并保证每天最多提示一次
- `TranslatorProvider`：创建按账号自动选择的翻译器

### 2. OCR 引擎 (`domain/ocr/`)
- `IOcrEngine`：OCR 接口
- `MLKitOcrEngine`：ML Kit 文字识别
- 智能识别字幕区域（屏幕底部 55%-98%）

### 3. 词典与难词提取 (`domain/dictionary/`、`domain/wordextractor/`)

词典数据来自开源的 **ECDICT**，打包为 SQLite 随应用分发，完全离线可用。

- `IDictionaryRepository`：查词接口（按语言绑定，多语言可扩展）
- `SqliteDictionaryRepository`：SQLite 实现，支持精确查询与**词形还原**（wolves → wolf、felt → feel）
- `DictionaryRepositoryProvider`：按语言注册词典，新增语言的接入点
- `IWordExtractor` / `LocalWordExtractor`：分词 → 查词典 → 评估难度 → 取前 N 个生词
- `IWordDifficultyAssessor` / `EnglishDifficultyAssessor`：依据词典中真实的**考试标签**（中考/高考/四六级/考研/托福/雅思/GRE）、**语料库词频**、**柯林斯星级**评估难度

### 4. 屏幕截图 (`domain/screenshot/`)
- `IScreenCaptureManager`：截图接口
- `ScreenCaptureManagerImpl`：MediaProjection 实现，带生命周期管理

### 5. UI 层 (`ui/`)
- `MainActivity`：Material 3 壳 + 底部导航 + 系统权限编排
- `HomeFragment` / `VocabularyFragment` / `LearningFragment` / `ProfileFragment`：四个 Tab
- `WordDetailActivity`：词汇详情、字幕上下文、例句、删除
- `WordReviewActivity`：单词卡片复习（认识 / 再复习）
- `LoginActivity` / `RegisterActivity`：邮箱密码登录与注册
- `SettingsActivity`：语言、OCR、媒体/无障碍权限等设置
- `TranslationOverlayView`：翻译结果悬浮窗

### 6. 账号与网络 (`domain/auth`、`data/auth`、`data/remote`)
- `AuthManager`：进程级登录状态（Loading / Guest / LoggedIn）
- `AuthRepositoryImpl`：注册、登录、恢复会话、登出
- `TokenRefresher`：Refresh Token 单飞轮换；401 只重试一次
- `SessionStore`：EncryptedSharedPreferences 安全存储；Keystore 不可用时降级为内存会话
- `AuthApi` + Retrofit：统一响应包裹、错误码映射、Authorization/语言/版本请求头

## 使用说明

1. 打开应用，点击"启动字幕翻译"
2. 授予悬浮窗和屏幕录制权限
3. 在设置中选择源语言和目标语言（默认英译中）
4. 如需字幕导航，在设置 →「媒体控制」中授予通知使用权
5. 在任意视频界面，点击悬浮按钮
6. 查看翻译结果和重点词汇，长按可复制；底部可切换上一句/下一句
7. 再次点击按钮关闭翻译并恢复播放

> 底部导航：首页 / 词汇 / 学习 / 我的。游客可以正常翻译和浏览本地词汇；
> 可本地收藏 30 个单词 / 20 个短语，达到上限后提示登录，登录后不限量并自动云端同步。
> 登录、偏好设置、语言设置和「关于我们」都在「我的」页。

> 字幕导航依赖播放器的 MediaSession：YouTube、VLC 等支持精确 seek 的播放器可用；
> 暂停状态下 seek 不刷新画面的播放器，会自动静音播放一小段来渲染目标帧。
> 没有有效时长时间线的会话（例如抖音信息流）需要开启无障碍诊断；
> 部分 DRM 播放器或浏览器不暴露会话，此时会提示找不到可控制的播放器。

## 账号与登录（当前版本）

- 后端联调地址由 Gradle 属性注入：`apiBaseUrl`（默认 `http://110.40.178.127/api/v1/`，
  可用 `gradle.properties` 或 `-PapiBaseUrl=...` 覆盖）。
- 服务端尚未配置 HTTPS：debug 构建允许明文以便联调；release 的
  `network_security_config.xml` 只放行该 IP。正式上线前必须切换到 HTTPS，
  并移除 `app/src/debug` 与 `app/src/main` 两处明文例外。
- 已接入接口：`POST /auth/register`、`/auth/login`、`/auth/refresh`、`/auth/logout`、
  `GET /me`、`GET /config`、`POST /vocabularies/sync`、`POST /sentences/sync`。
- Token：Access 15 分钟、Refresh 30 天，刷新时轮换；401 最多刷新并重试一次；
  刷新遇到网络错误时保留本地登录态，不会把人踢下线。
- 游客：可以翻译、浏览本地词汇和使用学习功能；可本地收藏 30 个单词 / 20 个短语，
  达到上限后提示登录。登录后收藏不限量，本地数据自动归入账号并云端同步。
- 注册需要同意服务端返回版本的条款/隐私政策。完整法律文本尚未提供，当前为占位说明，
  上线前必须替换为正式文本。
- 云端同步：生词与句子收藏各自使用独立端点和独立游标，登录/冷启动/本地收藏后自动增量同步，
  断网时保留 dirty 队列、联网补发；同步协议见 `docs/vocabulary-sync-api.md`。
- 客户端尚未实现：邮箱验证流程、资料编辑（服务端 `PATCH /me` 未实现）。

- 游客额度只限制新增，已超限的存量仍可查看、复习和删除；短语额度同时统计短语与字幕句子收藏。

- 学习历史目前只保存在本地，登录也不会同步到其他设备；会员同样没有云端历史。

- 本地词库是设备级的，换账号不会清空，会继续沿用并同步到新账号。

**生词筛选强度**（设置页可调）

「重点词汇」显示多少个词由此决定，改完下次启动翻译服务时生效：

| 档位 | 效果（16 句真实字幕实测） |
|---|---|
| 宽松（默认） | 平均 2.3 词/句，只有 1 句完全没词 |
| 适中 | 平均 1.6 词/句，3 句没词 |
| 严格 | 平均 0.3 词/句，12 句没词，只保留 GRE 级难词 |

如果觉得译文下经常没有词汇，就调到「宽松」；如果觉得混进了自己认识的词，就调到「严格」。
各档的门槛值集中在 `WordDifficultyFilter` 里，可以按自己的词汇量改。

## 翻译通道（按登录态自动选择）

设置页不再提供引擎选项，翻译通道由登录态自动决定：

| 角色 | 基础翻译通道 | 说明 |
|---|---|---|
| 游客（未登录） | ML Kit 端侧 | 不发起任何云端请求，无需联网 |
| 免费账号（登录） | 云端优先，每日 10 次 | 超额或云端失败时自动回退 ML Kit |
| 会员（登录） | 云端优先，不限次数 | 服务端返回 `unlimited=true` |

设备不再直连百度或 Google：第三方翻译凭据（APP ID、Secret、API Key）只配置在
`subtitle-translator-server`，客户端只调用后端 `POST /api/v1/translations/text`。

**额度协议**：成功响应在 `data.quota` 返回当日额度（`limit` / `used` / `remaining` /
`resetAt` / `unlimited`）；超额返回 HTTP 429，错误码 `QUOTA_EXCEEDED`，`error.details`
直接带 `limit` / `retryAfterSeconds` / `resetsAt` / `timeZone`。客户端兼容旧契约的
`TRANSLATION_DAILY_QUOTA_EXCEEDED` + `error.details.quota`。翻译请求由 OkHttp 拦截器统一附加
`X-Client-Timezone: <IANA 时区>`，服务端据此计算每日额度的重置时刻。
客户端不主动查询额度（没有 GET quota 接口），只消费翻译响应里的字段并缓存最近一次结果：
`remaining=0` 时直接走本地，避免重复请求；每个重置周期最多提示一次，提示后打开主应用的受限弹窗。
登录、退出或账号切换后缓存自动失效。

**云端失败时都会自动回退到 ML Kit**（断网、接口未开放、语言对不受支持、供应商限流或故障、
额度用尽），所以不会出现「完全翻译不出来」的情况，最差也只是退回离线质量。

**服务端开关**：后端默认关闭该接口（`EXTERNAL_TRANSLATION_ENABLED=false`，返回 404）。
部署时需设置 `EXTERNAL_TRANSLATION_ENABLED=true` 并通过 `EXTERNAL_TRANSLATION_PROVIDER`
选择 `baidu` 或 `google`、配置对应凭据；未开启时客户端自动回退到 ML Kit。

## AI 翻译纠错（会员）

翻译面板「译文」标题右侧的 AI 图标是手动触发的翻译纠错入口，和上面的基础翻译通道相互独立：

- **默认暗色**表示当前译文来自基础翻译；点击后上传识别时的字幕区域截图，调用后端
  `POST /api/v1/translations/ai/image`。服务端多模态模型同时重新识别原文并精译，
  返回后原文、译文和生词卡一起刷新，图标变为强调色。
- 上传的是裁剪后的字幕区域 JPEG（长边 ≤ 2560 px、≤ 5 MB），不是整屏截图。截图在字幕
  识别阶段缓存，点击时不会再截一次，因为翻译面板本身会遮住字幕区域。
- 请求携带最近 **4 组已展示的字幕对**作为上下文；切换语言方向或重新授权录屏后清空，
  不发送整段历史。当前句本身不会作为上下文重复发送。
- 图片翻译要求具体的源语言：源语言设为「自动」时会提示不支持，需先在设置里指定语言。
- **失败不覆盖现有译文**：游客提示登录，免费账号提示仅限会员，截图中没有字幕或图片
  无法处理时分别提示；请求进行中图标持续旋转并禁用，避免连点重复计费。
- 切换字幕或关闭面板后，迟到的旧结果会被丢弃。
- AI 结果会更新本地历史中最近一条同原文记录；原文和译文一起替换，不会新增重复记录。

服务端需要设置 `AI_ENABLED=true` 才会注册该接口（默认 404）；当前渠道尚未接入订阅，
所有登录用户在服务端仍是免费账号，因此会返回 403 `MEMBERSHIP_REQUIRED`。
接入 Google Play 订阅或直接把测试账号的 `plan` 设为 `member` 后即可使用。

## 调试截图（排查识别不准）

识别不准时，光看结果无法判断问题出在哪一环。在**设置 → 调试截图**里打开开关后，
每次识别会保存三个阶段：

| 文件 | 内容 | 用来判断 |
|---|---|---|
| `1_screenshot.jpg` | 原始截图 | 截图本身是否正常（黑屏、截到加载画面） |
| `2_subtitle.png` | 裁剪出的字幕区域 | 裁剪位置是否切对，字幕有没有落在框外 |
| `3_processed.png` | 预处理后喂给 OCR 的图 | 灰度+二值化是否把笔画吃掉了 |

同时记录当次 OCR 原文、译文、裁剪参数、缩放倍数、预处理方式和失败原因。

### OCR 预处理方式（设置页可切换）

字幕颜色与视频背景接近时，**全局固定阈值二值化会把两者处理成同一种颜色，文字直接消失** ——
文字亮度 150、背景 140 时，阈值取 128 两者都变白，取 160 两者都变黑，
只有恰好落在两者之间才行，而这个区间每帧都在变。所以这不是调阈值能解决的问题。

因此默认不再二值化，保留原始明暗差异交给 OCR 模型（ML Kit 是在自然图像上训练的，
本身能处理低对比度，硬二值化反而会丢掉抗锯齿边缘和细笔画）：

| 方式 | 说明 |
|---|---|
| **灰度（默认）** | 只转灰度、不二值化，保留明暗层次。字幕与背景颜色接近时用这个 |
| 自适应二值化 | 按每个像素邻域的亮度单独取阈值（邻域均值 + 偏置），能适应画面明暗不均 |
| 固定阈值二值化 | 全图一个阈值，原实现，保留用于对比 |

配合调试截图使用：开启后能看到「预处理图」，换一种方式再识别一次就能直接对比。

查看入口：设置 → 调试截图 → 查看最近记录（打开开关后，悬浮球长按菜单里也会出现「识别截图」）。
列表按时间倒序，点任意缩略图可放大查看并**分享**出去。

存储位置是应用私有目录 `filesDir/debug_captures/`：**不需要任何存储权限**，
也不会出现在系统相册里（字幕截图可能含聊天记录等隐私内容）。只保留最近 **5 次**（约 6MB），
超出后自动删除最旧的。开关立即生效，不必重启服务。

## 无障碍诊断（播放器控件树）

部分播放器（例如抖音长视频）不暴露可 seek 的 MediaSession。为了确认进度条到底能不能通过
无障碍接口操作，可以在 **设置 → 无障碍诊断** 中开启诊断服务，然后在播放器内长按悬浮球，
选择 **无障碍诊断**。

节点树会以 `A11yDump` 标签输出到 logcat，重点看：

- `SEEK_CANDIDATE` 开头的行：节点带 `range(...)`，或 class 是 `SeekBar` / `ProgressBar`
- 节点的 `actions` 是否包含 `ACTION_SET_PROGRESS` / `ACTION_SEEK_TO`

抓取日志：

```bash
adb logcat -s A11yDump
```

诊断服务只在你主动触发时读取当前窗口节点，不会自动读取、上传屏幕内容。

如果当前播放器的进度条是标准 `SeekBar`（抖音长视频就是），开启无障碍诊断后，
上一句/下一句会优先通过节点的 `ACTION_SET_PROGRESS` 精确设置进度，
不再依赖 MediaSession。播放控件自动隐藏时会先在视频**非中心区域**点一下把控件唤出，
不需要用户手动点屏幕；点中心会暂停/播放，所以不会点中心。截图前的最后一步会在同一区域
再点一下收起控件，并通过无障碍节点确认进度条真的消失后再截图；仍可见时最多再点一次。

MediaSession 路径同样采用「设进度 → 静音播放一小段 → 暂停 → 截图」的流程：
很多播放器在暂停状态下 seek 只移动进度条、不重新渲染画面，直接截图会一直读到旧字幕。

如果无障碍服务未开启、且当前播放器的 MediaSession 没有可用时间线（例如抖音的
信息流会话 `position=0`、`duration=null`），导航会收起翻译面板并直接打开系统
无障碍设置，提示用户开启「字幕拾词诊断」，开启后重新翻译即可。
引导期间**视频保持暂停**，不会恢复播放把观看位置跳走。

## 词典数据

词典由 [ECDICT](https://github.com/skywind3000/ECDICT)（MIT License, Copyright (c) Linwei）
转换而来，构建脚本为 `scripts/import_ecdict.py`：

```bash
# 自动下载源数据（约 68MB）并构建
python3 scripts/import_ecdict.py --download

# 或用本地已有的源数据
python3 scripts/import_ecdict.py --csv ecdict.csv --lemma lemma.en.txt
```

脚本产物 `app/src/main/assets/dictionary.db` 已入库，克隆后可直接编译，无需重新生成。

**裁剪策略**：ECDICT 全量 77 万条，绝大部分是极罕见词、短语和专有名词。
脚本只保留「字幕里真正常见」的词——有语料库词频排名、或有考试大纲标签、
或有柯林斯星级、或是牛津核心词，最终 **59,137 条**（约 16MB）。

**词形还原**：`word_form` 表记录屈折形式到原形的映射（约 5 万条），
数据来自 ECDICT 的 `lemma.en.txt` 与 `exchange` 字段。

**多语言扩展**：新增语言只需三步，上层代码无需改动——
用类似的脚本生成 `assets/dictionary_xx.db`、实现该语言的释义解析器
（`WordSenseParser`）、在 `DictionaryRepositoryProvider.DEFAULT_SOURCES` 中登记。
