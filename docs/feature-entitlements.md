# 功能权限与会员体系改造计划

本文档整理游客、免费账号、会员三档权限矩阵，对照当前实现列出差距，并给出分阶段改造计划。
AI 相关功能目前均未实现，本文档同时定义它们与现有免费能力的边界。

## 1. 角色定义

| 角色 | 判定 | 产品定位 |
| --- | --- | --- |
| 游客 | `AuthState.Guest`（未登录） | 完整体验基础学习流程，数据本地保存，有少量额度 |
| 免费账号 | 已登录且无有效会员 | 建立个人云端学习资料库，多设备同步，不限收藏量 |
| 会员 | 已登录且会员在有效期内 | AI 驱动的识别、翻译、语境讲解与练习，高级学习报告 |

会员状态以服务端为准；客户端只做入口控制与展示，AI 接口必须在服务端再次校验会员与额度。

## 3. 边界与额度定义

### 收藏额度（游客）

- 游客最多保存 30 个单词、20 个短语，计数以本地词库为准。
- 达到上限时**不删除已有收藏**，仅阻止新增，并弹出登录引导：
  “登录后收藏不限数量，并自动云端备份”。
- 升级前的存量数据不回收：若游客已有超过上限的数据（例如旧版本遗留），仍可正常查看、复习、删除，
  只是不能继续新增；删除到上限以下后恢复新增。
- 登出后本地数据保留，额度规则重新生效。
- 免费账号与会员不限制收藏数量。收藏是学习资产，积累越多迁移成本越高。

### 学习历史（游客）

- 游客只能查看最近 3 个自然日（含今天）的翻译记录。
- 更早的记录仍保留在本地数据库，不做删除；登录后立即可见完整历史，避免升级即丢数据。
- 首页“近三天记录”和详情页“查看全部”都按同一时间窗过滤。

### 单词本管理：基础 vs 完整

- **基础（游客）**：查看列表、搜索、发音、删除单条。
- **完整（免费账号及以上）**：在基础之上增加按单词/短语筛选、按时间/字母排序、批量清空。
- 筛选与排序按钮对游客隐藏或置灰，并给出登录提示；搜索保持可用，避免基础体验被破坏。

### 学习进度管理（免费账号及以上）

- 自定义每日复习目标（当前固定 10）。
- 手动调整单词学习状态（学习中 / 已掌握）、重置单个词或整本的复习进度。
- 游客不显示进度管理入口，保留默认目标的进度展示（但统计本身对游客隐藏，见下）。

### 基础复习：体验 vs 完整

- **体验（游客）**：每日最多复习 10 张卡片，仅开放“待复习”模式；达到上限后提示登录。
- **完整（免费账号及以上）**：不限张数，“待复习”和“全部卡片”两种模式都可用。
- 游客的复习记录仍写入本地，登录后计入账号。

### 基础学习统计

- 学习 Tab 的目标进度、待复习数、已掌握数只对登录用户展示。
- 游客进入学习 Tab 时展示引导卡片（登录后解锁统计与完整复习），而不是零值统计。
- 首页的翻译/复习统计卡片同样对游客隐藏或替换为引导。

### 云端数据备份与多设备同步（免费账号及以上）

- 生词、短语、句子收藏、自定义分类、学习历史、学习进度全部云端同步。
- 本地优先：先写 SQLite 立即刷新 UI，后台增量同步；离线可用，联网补发。
- 游客数据在登录后自动归入账号，不需要“合并确认”。

### 自定义分类（免费账号及以上）

- 用户可创建、重命名、删除分类，并给收藏条目归类。
- 分类作为独立同步资源，保证多设备 ID 稳定；删除分类时条目回到“未分类”，不删除条目。

### AI 能力（仅会员）

- **AI 字幕识别**：本地 OCR 置信度低或结果为空时，把当前帧交给云端多模态模型纠错、
  剔除播放器 UI 文本、合并断行。默认手动触发，避免流量与费用不可控。
- **AI 翻译**：结合前后字幕、语气和场景的整段精译，处理俚语、省略句和双关；
  失败时回退到基础翻译结果。
- **AI 语境分析**：查词时解释该词在当前句子中的含义、语气、常见搭配和易混淆点。
- **AI 自动发现口语**：翻译过程中自动识别值得收藏的口语表达、俚语和固定搭配，
  给出释义并支持一键收藏；只处理当前字幕，不上传整段视频。
- **AI 生成练习**：基于用户已收藏的单词和短语生成语境填空、同义替换、造句等练习。
- **高级学习报告**：连续学习天数、每日趋势、分类分布、复习正确率、历史对比。

所有 AI 请求必须携带登录态，服务端按 plan 和额度校验；客户端 `FeatureGate` 只负责体验，
不作为安全边界。AI 结果需标记来源（本地 OCR / 基础翻译 / AI），避免用户误解。

## 4. 现状差距

1. **游客收藏被登录拦截且有上限缺失**
   `service/FloatingButtonService.kt` 保存单词/句子前调用 `authManager.isLoggedIn()`，
   未登录走 `requestLoginForSave`；本地没有任何 30/20 的额度判断。
2. **学习历史没有时间窗**
   `TranslationHistoryActivity` 直接展示全部记录，游客与登录用户无差别。
3. **统计与复习未分级**
   `LearningFragment` 对游客展示完整统计；`WordReviewViewModel` 对游客不限张数、两种模式全开。
4. **单词本管理未分级**
   搜索、筛选、排序、清空对所有角色开放，没有“基础/完整”之分。
5. **没有自定义分类**
   数据库、领域模型、同步协议和 UI 均无分类概念。
6. **没有学习进度管理**
   每日目标固定 10，没有修改入口；学习状态只能在复习过程中被动变化。
7. **学习历史没有云端能力**
   `translation_records` 表没有 `remote_id` / `sync_state` / `deleted_at` / `client_ref_id` / `updated_at`，
   没有同步管理器和接口契约；清除历史只清本地。
8. **没有会员/权益模型**
   `AuthUser` 没有 plan / 到期时间字段；代码中不存在 `isMember`、`membership`、`vip` 等概念。
9. **没有升级入口**
   “我的”页面没有会员卡片或权益说明。
10. **AI 功能全部未实现**
    浮窗只有基础翻译链路，没有 AI 引擎、入口或服务端契约。

## 5. 修改计划

### 阶段一：权限底座

目标：把“角色 + 功能”变成可复用的领域概念，后续所有额度与入口都走同一套判断。

改动：

- 新增 `domain/entitlement/`：
  - `Plan`（`GUEST` / `FREE` / `MEMBER`）、`Membership(plan, expiresAt)`、`Entitlement(user, plan)`；
  - `Feature` 枚举：单词本完整管理、自定义分类、进度管理、完整复习、基础统计、云端同步、
    高级报告、AI 字幕识别、AI 翻译、AI 语境分析、AI 自动发现口语、AI 生成练习；
  - `IEntitlementManager`：暴露 `StateFlow<Entitlement>`，由 `AuthState` + 会员信息合成。
- 服务端用户信息增加 `plan`、`plan_expires_at`（缺省视为 `FREE`，客户端宽松解析，兼容旧版本）；
  本地缓存最近一次会员状态，离线时仍按缓存展示入口，AI 请求由服务端最终裁决。
- 新增 `ui/common/entitlement/FeatureGate`：游客 → 复用 `LoginGate`；免费账号 → 会员权益 BottomSheet；
  `Feature` 的展示名称与说明由 `TextMappings` 映射，不在 ViewModel 中拼接文案。
- 新增通用的额度判断（`EntitlementQuota` / 本地计数），供收藏、复习、历史时间窗复用。

验收：三档角色得到不同 `Entitlement`；权限变化无需重启即刷新；未登录时同步器仍安全空转。

### 阶段二：游客体验与额度（对齐矩阵）

目标：游客不登录即可完整走通“看字幕 → 查词 → 收藏 → 复习”，同时落实 30/20/3 天/体验复习的边界。

改动：

- `FloatingButtonService`：删除保存前的登录判断与 `PendingSave` 登录等待逻辑；
  保存前检查游客额度，未超限直接写本地，超限弹出登录引导（底部 Sheet，复用现有样式）。
- 收藏额度：新增本地计数与上限常量（单词 30、短语 20），在仓库层或 ViewModel 统一判断；
  存量超限数据不回收，只阻止新增。短语计数需明确是否包含句子收藏（见待确认项）。
- 学习历史：`TranslationHistoryDetailViewModel` / 首页统计按“最近 3 个自然日”过滤游客数据；
  登录后自动展示全部，不删除旧数据。
- 学习 Tab：游客不展示统计数值，改为登录引导卡片；登录用户维持现状。
- 单词本：游客隐藏筛选/排序/清空入口，保留列表、搜索、发音、单条删除。
- 复习：游客每日 10 张、仅“待复习”模式；达到上限提示登录。复习结果仍写本地。
- 测试：覆盖额度边界（第 30/31 个单词、第 20/21 个短语）、3 天窗口、游客复习上限、
  游客保存不被登录拦截。

验收：游客可连续收藏到上限并收到登录引导；历史只显示 3 天；学习 Tab 显示引导；
复习第 11 张被拦截；所有数据在登录后完整可见并自动上传。

### 阶段三：账号数据资产

目标：免费账号拥有完整词库管理、自定义分类、进度管理与云端历史。

改动：

- 自定义分类：新增 `categories` 表与 `saved_words.category_id`；领域模型与仓库接口；
  词库页支持创建/重命名/删除分类、按分类筛选、条目归类。
- 学习进度管理：每日目标可配置（写入 `SettingsStore`）；单词详情/列表支持调整学习状态、
  重置复习进度。
- 学习历史同步：`TranslationHistoryDatabaseHelper` 升级到 v2，增加
  `client_ref_id`、`remote_id`、`updated_at`、`deleted_at`、`sync_state`；旧数据迁移为待上传。
  新增 `HistorySyncManager` + `SharedPrefsHistorySyncStateStore`，接入 `SyncCoordinator`。
  服务端新增 `POST /api/v1/history/sync`，协议复用现有批量增量模式。
- 分类同步：新增 `POST /api/v1/categories/sync`，生词 DTO 增加 `category_id`。
- 清除历史：本地 tombstone + 云端删除；服务端保留期建议 180 天。
- 隐私：登录后默认同步（免费账号明确权益），偏好设置提供“云端保存学习历史”开关；
  隐私政策说明存储内容、保留期与删除方式。
- 更新 `docs/vocabulary-sync-api.md` 或新增历史/分类同步契约文档。

验收：两台设备登录同一账号后收藏、分类、进度、历史一致；一台删除另一台同步消失；
游客数据登录后不重复、不丢失；游客旧历史在登录后完整出现。

### 阶段四：会员与 AI 能力

目标：交付会员差异化能力，每一项都带服务端鉴权与额度控制。

建议顺序与要点：

1. **会员入口**：“我的”页会员卡片（游客：登录后云端同步；免费：升级会员；会员：到期时间），
   会员权益 BottomSheet，支付由服务端/网页完成，回跳后刷新权益，到期自动降级、数据保留。
2. **AI 翻译**：浮窗结果增加“AI 精译”，携带前后字幕作为上下文；服务端校验会员与每日额度，
   超限返回统一错误码并映射为升级/额度提示；失败回退基础翻译。
3. **AI 语境分析**：查词弹层增加“语境解释”，输出当前句中的词义、语气、搭配；结果可缓存。
4. **AI 自动发现口语**：翻译当前句时识别口语表达/俚语/固定搭配，浮窗内提示一键收藏。
5. **AI 生成练习**：学习 Tab 或复习页增加“AI 练习”入口，基于收藏词生成语境填空、同义替换、造句。
6. **AI 字幕识别**：本地 OCR 置信度低时提供“AI 识别”按钮，上传当前帧返回纠错字幕。
7. **高级学习报告**：连续天数、趋势图、分类分布、正确率、历史对比。

通用约束：

- 所有 AI 请求必须登录并由服务端按 plan/额度校验；客户端 Gate 不是安全边界。
- 未上线前不放置可点击的假入口；会员卡片以“即将上线”列出权益，避免点击落空。
- AI 成本控制：服务端额度、结果缓存、默认手动触发、失败回退免费能力。

### 阶段五：合规与运营

- 隐私政策补充：云端历史、自定义分类、AI 识别上传的截帧、保留期、删除路径。
- 会员协议、自动续费说明、退款入口。
- 埋点：收藏数、登录转化、会员入口点击、AI 功能使用与失败率；不采集字幕原文。

## 6. 风险与对策

| 风险 | 对策 |
| --- | --- |
| 收藏额度让游客觉得受限 | 明确提示“登录免费且不限量”，额度只拦新增不删数据；登录流程足够短 |
| 登出后本地数据超过游客额度 | 允许查看/复习/删除，只阻止新增，避免数据“消失” |
| 3 天历史窗口引发“数据丢了”误解 | 历史页说明“更早记录登录后可见”，登录后完整恢复 |
| 取消登录拦截后注册转化下降 | 在收藏达上限、复习达上限、查看统计等节点做非阻断式引导 |
| 云端历史带来隐私顾虑 | 默认同步但可关闭，提供清除与保留期说明 |
| 会员到期离线仍显示会员 | 本地缓存带到期时间，过期即按免费版展示；AI 请求服务端兜底 |
| AI 成本失控 | 服务端额度、结果缓存、默认手动触发、失败回退免费能力 |

## 7. 待确认的产品决策

1. 会员支付渠道：应用内购买还是网页支付（影响客户端接入与合规文案）。
2. 短语额度 20 个是否包含“句子收藏”，以及达到上限时是阻止新增还是提示替换最旧一条。
3. “单词本管理 基础/完整”的边界：本文档建议游客保留搜索，只限制筛选、排序与批量清空。
4. 游客“基础复习体验”的额度：本文档建议每日 10 张且仅“待复习”模式。
5. 高级学习报告的具体指标清单与展示位置（首页 / 学习页 / 独立页面）。
6. 游客超过 3 天的历史：本文档建议保留本地、仅隐藏，登录后恢复。
