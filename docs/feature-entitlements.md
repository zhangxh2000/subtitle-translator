# 功能权限与会员体系改造计划

本文档整理游客、注册免费用户、会员三档权限矩阵，对照当前实现列出差距，并给出分阶段改造计划。
AI 相关功能目前均未实现，本文档同时定义它们与现有免费能力的边界。

## 1. 角色定义

| 角色 | 判定 | 产品定位 |
| --- | --- | --- |
| 游客 | `AuthState.Guest`（未登录） | 完整体验基础学习流程，数据本地保存 |
| 注册免费 | 已登录且无有效会员 | 建立个人云端学习资料库，多设备同步 |
| 会员 | 已登录且会员在有效期内 | AI 驱动的识别、翻译与讲解能力，完整统计 |

会员状态以服务端为准；客户端只做展示与入口控制，AI 接口必须在服务端再次校验会员与额度。

单条收藏数据量很小，云端存储成本可以接受。

## 3. 能力边界定义

### 基础翻译 vs AI 翻译

- **基础翻译**：现有翻译引擎，逐句独立翻译，速度快、成本低，允许游客无限使用。
- **AI 翻译**：结合前后字幕、语气和场景的整段翻译，能处理俚语、省略句和双关；延迟更高，
  仅会员可用。入口为浮窗翻译结果上的“AI 精译”，失败时回退到基础翻译结果。

### 本地 OCR vs AI 识别

- **本地 OCR**：MediaProjection 截帧后由 ML Kit 端侧识别，免费、离线、隐私好。
- **AI 识别**：把截帧交给云端多模态模型，纠正 OCR 错字、剔除播放器 UI 文本、合并断行，
  在本地 OCR 置信度低或识别结果为空时触发，仅会员可用。

### 单词复习 vs AI 词汇复习

- **单词复习**：现有 SRS 流程（新词 / 学习中 / 已掌握），所有角色可用。
- **AI 词汇复习**：基于用户已收藏词汇生成语境填空、同义替换、造句练习，仅会员可用。

### 基础统计 vs 完整统计

- **基础统计**：收藏总数、单词/短语数、待复习、已掌握、今日复习进度（现有 `LearningStats`）。
- **完整统计**：连续学习天数、每日趋势、按难度/来源分布、复习正确率、历史对比，仅会员可用。

### 收藏的本地与云端

- 游客收藏写入本地 SQLite，立即生效，不弹登录框。
- 登录后本地未同步记录自动上传（现有 dirty 队列 + `client_ref_id` 幂等机制已支持）。
- 游客状态下取消收藏同样只改本地，登录后不需要“合并确认”。

## 4. 现状差距

1. **游客收藏被登录拦截**
   `service/FloatingButtonService.kt` 中保存单词/句子前调用 `authManager.isLoggedIn()`，
   未登录时走 `requestLoginForSave`，与“游客免费本地收藏”直接冲突。
2. **学习历史没有云端能力**
   `translation_records` 表没有 `remote_id` / `sync_state` / `deleted_at` / `client_ref_id` / `updated_at`，
   也没有对应的同步管理器和接口契约；清除历史只清本地。
3. **没有会员/权益模型**
   `domain/auth/AuthModels.kt` 的 `AuthUser` 没有 plan / 到期时间字段；
   代码中不存在 `isMember`、`membership`、`vip` 等概念，所有功能对登录用户一视同仁。
4. **没有升级入口**
   “我的”页面只有登录/注册、语言设置、偏好设置、关于、退出登录，没有会员卡片或权益说明。
5. **AI 功能全部未实现**
   浮窗只有基础翻译链路，没有 AI 引擎、AI 入口或服务端契约。

## 5. 修改计划

### 阶段一：游客本地收藏（消除现有冲突）

目标：游客不登录也能完整走通“看字幕 → 查词 → 收藏 → 复习”。

改动：

- `FloatingButtonService`：删除保存前的登录判断与 `PendingSave` 登录等待逻辑，
  单词和句子收藏一律先写本地，再交给现有 `SyncCoordinator`（未登录时同步器直接返回）。
- `LoginGate`：移除 `LoginFeature.SAVE_WORD` 及对应文案；登录引导只保留主动登录和云端相关场景。
- 游客首次收藏后不做打断式提示；在“生词本”页顶部为游客展示一条可关闭的
  “登录后自动云端备份”提示条，把注册引导放在自然位置。
- 测试：更新断言“游客保存被拦截”的用例，改为断言游客可保存、列表可见、复习可用。

验收：游客点击收藏立即生效，无登录弹层；杀进程重开数据仍在；登录后已收藏内容自动上传。

### 阶段二：权限模型与会员入口

目标：把“角色”变成可复用的领域概念，任何功能都能声明最低权限。

改动：

- 新增 `domain/entitlement/`：
  - `Plan`（`GUEST` / `FREE` / `MEMBER`）、`Membership(plan, expiresAt)`、`Entitlement(user, plan)`；
  - `Feature` 枚举：AI 识别、AI 翻译、AI 语境解释、AI 口语分析、AI 俚语分析、AI 例句、AI 复习、完整统计；
  - `IEntitlementManager`：暴露 `StateFlow<Entitlement>`，由 `AuthState` + 会员信息合成。
- 服务端用户信息增加 `plan`、`plan_expires_at`（缺省视为 `FREE`，客户端宽松解析，兼容旧版本）；
  本地缓存最近一次会员状态，离线时仍按缓存展示入口，AI 请求由服务端最终裁决。
- 新增 `ui/common/entitlement/FeatureGate`：游客 → 复用 `LoginGate`；免费用户 → 会员权益 BottomSheet；
  会员 → 直接执行。样式与现有 `LoginRequiredBottomSheet` 一致。
- “我的”页面增加会员卡片：游客显示“登录后开启云端同步”，免费用户显示“升级会员”，
  会员显示到期时间。
- 所有会员功能入口统一走 `FeatureGate`，`Feature` 的展示名称和说明由 `TextMappings` 映射，
  不在 ViewModel 中拼接文案。

验收：三档角色看到不同入口；免费用户点会员功能只出现升级引导；会员状态变更后无需重启即刷新。

### 阶段三：学习历史云端同步

目标：注册用户的历史记录多设备可见，游客历史在登录后自动归入账号。

改动：

- `TranslationHistoryDatabaseHelper` 升级到 v2：增加 `client_ref_id`、`remote_id`、`updated_at`、
  `deleted_at`、`sync_state`，旧数据迁移为待上传（首次登录时回填）。
- 服务端新增 `POST /api/v1/history/sync`，协议复用生词/句子的批量增量模式：
  push 变更 + pull 增量 + 游标，`client_ref_id` 幂等，删除用 tombstone。
- 新增 `HistorySyncManager`、`SharedPrefsHistorySyncStateStore`，接入 `SyncCoordinator`，
  与生词、句子同步互不阻塞。
- 历史页增加“清除历史”：本地 tombstone + 云端删除；服务端保留期建议 180 天，客户端本地保留上限维持现状。
- 隐私：登录后默认同步（这是免费版明确权益），但在偏好设置提供“云端保存学习历史”开关；
  首次同步前在隐私政策中说明存储内容、保留期与删除方式。
- 更新 `docs/vocabulary-sync-api.md` 或新增历史同步契约文档。

验收：两台设备登录同一账号后历史一致；一台删除另一台同步消失；游客历史登录后不重复、不丢失。

### 阶段四：会员能力与 AI 功能

目标：按价值排序逐步交付 AI 能力，每一项都带服务端鉴权与额度控制。

建议顺序与要点：

1. **AI 翻译**：浮窗结果增加“AI 精译”，携带前后字幕作为上下文；服务端校验会员与每日额度，
   超限返回统一错误码，客户端映射为升级/额度提示；失败回退基础翻译。
2. **AI 单词语境解释**：查词弹层增加“语境解释”，输出该句中的词义、语气、常见搭配；
   结果可缓存，避免重复计费。
3. **AI 例句生成**：单词详情页生成 2–3 条贴近用户水平的例句，支持收藏例句。
4. **AI 字幕识别**：本地 OCR 置信度低或结果为空时提供“AI 识别”按钮，上传当前帧，
   返回纠错后的字幕；默认不自动触发，避免流量与费用不可控。
5. **AI 口语表达分析 / 俚语与固定搭配分析**：面向已收藏句子，给出自然度、语域、替代表达。
6. **AI 词汇复习**：基于收藏词生成语境练习，作为现有 SRS 的补充模式。
7. **完整学习统计**：连续天数、趋势图、分类分布、正确率；数据来自本地 + 云端聚合。

通用约束：

- 所有 AI 请求必须携带登录态，服务端按 plan 和额度校验；客户端 `FeatureGate` 只负责体验，不作为安全边界。
- AI 结果统一标记来源（本地 OCR / 基础翻译 / AI），避免用户误解。
- 未上线前不放置可点击的假入口；会员卡片以“即将上线”列出权益，避免点击落空。
- 支付与订阅由服务端/网页完成，客户端只负责拉起、回跳后刷新权益；到期自动降级为免费版，数据保留。

### 阶段五：合规与运营

- 隐私政策补充：云端历史、AI 识别上传的截帧、保留期、删除路径。
- 会员协议、自动续费说明、退款入口。
- 埋点：收藏数、登录转化、会员入口点击、AI 功能使用与失败率；不采集字幕原文。

## 6. 风险与对策

| 风险 | 对策 |
| --- | --- |
| 取消登录拦截后注册转化下降 | 在收藏达到一定数量、连续学习等节点做非阻断式引导，不恢复强制登录 |
| 云端历史带来隐私顾虑 | 默认同步但可关闭，提供清除与保留期说明，敏感内容不上传 |
| 会员到期离线仍显示会员 | 本地缓存带到期时间，过期即按免费版展示；AI 请求服务端兜底 |
| 游客首次登录上传数据量大 | 分页上传 + 指数退避（现有同步器已具备），失败不阻塞使用 |
| AI 成本失控 | 服务端额度、结果缓存、默认手动触发、失败回退免费能力 |

## 7. 待确认的产品决策

1. 会员支付渠道：应用内购买还是网页支付（影响客户端接入与合规文案）。
2. 云端历史保留期与是否允许用户彻底关闭同步。
3. AI 翻译的免费试用额度（如每月 3 次）是否作为转化手段。
4. “完整学习统计”的具体指标清单与展示位置（首页 / 学习页 / 独立页面）。
